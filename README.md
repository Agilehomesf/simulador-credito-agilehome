# Agile Home
Sitio web de Agile Home y Agile Match (Colombia).
- `index.html`: página principal de Agile Home.
- `img/`: imágenes de la página.
- `simulador.html`: Agile Match, versión pública para clientes.
- `legado/`: versión anterior (Flask), solo como respaldo.

Publicado con GitHub Pages. Tasas de cartelera sujetas a confirmación con cada entidad.
